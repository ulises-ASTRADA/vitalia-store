# Etiquetas Vitalia

46 fotos con etiquetas de la marca anterior se actualizaron con el logo aprobado de Vitalia mediante montaje por código. Las zonas de marca se indican en etiquetas-vitalia.json. El resto de los píxeles se conservó exactamente al guardar como WebP sin pérdida. Las otras 249 fotos de productos no se modificaron.

Los nombres, ingredientes, claims, fechas, cantidades y tablas nutricionales originales no se reescribieron. La prueba generativa inicial, que alteraba ingredientes, no se incorporó al proyecto.

Las fotos originales se conservan en la versión anterior del ZIP. El registro contiene las áreas intervenidas y los hashes de origen y resultado.
